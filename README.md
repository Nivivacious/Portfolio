# Nivedita Prabhu · Portfolio

"Twelve years on the board. Strategy, settled first."

A Catan-style interactive portfolio: an island board where each labelled hex opens a section of the work, a roll-the-dice tour that walks through every section in order, and a quick playable game against a computer opponent that reveals facts about Nivedita as it goes.

It's a single static page (`index.html`) with no build step. Deployed on Vercel.
